Translator

On Follow main provider the translator uses the same billing as your main reasoning provider — except that a CLI provider takes about ten seconds per translation, which breaks translate-as-you-type. So when MARSHAL_API_KEY is set, the translator takes the fast API instead (local OCR on macOS) and the chat keeps its own provider. Pin an explicit backend to override that, or to put the translator on a different account than the chat.

Voice dictation

Hold to record, release to transcribe. Default RightCmd (just hold the right Command key). Combos also work, e.g. Cmd+Shift+D.

Milliseconds before recording starts. 200 ignores accidental taps; 0 starts immediately.

Toggle mode is useful for longer dictation. When enabled, holding is disabled for that hotkey.

Hybrid prefers Groq's cloud whisper-large-v3 (free tier: ~4 hrs audio/day) and falls back to local ggml-large-v3-turbo automatically on errors. Run npm run setup:dictation once to provision the local model.

Picks the input device for the next recording. While dictation is active Marshal temporarily sets this as the system default input and restores it on release. Refresh list after plugging in a new mic.

Pin a language if auto-detect misfires on short utterances — e.g. Ukrainian getting recognised as Russian. Auto works well for longer clips.

Huge accuracy win on mixed-language speech (Ukrainian + English tech terms) and rare words. Whisper caps this at ≈1000 characters. Leave blank to disable. Restore default.

Live captions

Subtitles and a 2–3 bullet AI summary of whatever the Mac is playing, on an overlay that screen sharing cannot see. Toggle with the hotkey below or from the tray.

Electron accelerator syntax, e.g. CommandOrControl+Alt+Shift+C. Applies on save.

First press picks the region with the crop overlay; later presses OCR it silently into the summary. Tray → Live Captions → Reset OCR Region… to pick again.

The overlay is click-through; it accepts the mouse only while this key is held. Modifier names as for dictation (LeftControl, RightOption…); off disables it — the tray toggle still works.

Pick the fastest model the account serves — the first bullet should land within a second. Only used with the OpenAI-compatible provider; the Anthropic one uses MARSHAL_CAPTIONS_CLAUDE_MODEL (default claude-haiku-4-5).

Mixes the dictation microphone into the stream, in sync with the system audio. Use headphones: on speakers the mic hears the other side too and everything doubles. Needs macOS 15 and the Microphone permission (asked on first start).

Decides which frames are speech. Energy is the fallback Marshal uses automatically if the Silero model fails to load.

Milliseconds of silence that close a sentence and trigger the summary. 900 is the default; raise towards 1200–1500 for slow speakers, lower for fast ones — every 100 ms here is 100 ms of caption latency.

Cuts roughly half a second off each turn. Costs extra whisper calls on mid-sentence pauses — fine on Groq, noticeable CPU with local whisper.cpp.

Drop Markdown or text files here — meeting agenda, project log, glossary. They help the summary spell names and technical terms right; the bullets only ever restate what was said. Up to ~12k characters; picked up automatically when a file changes.

Updates

Polls the GitHub Releases API once on launch and every 6 hours. Notification surfaces new versions; you install the .dmg manually (auto-install is gated on code-signing — see #78).

Marshal is signed with a stable self-signed certificate, so from v0.1.3 onwards your Microphone / Accessibility / Screen Recording permissions persist across updates. The first v0.1.3 install will still re-prompt (one-time transition from the old ad-hoc signature); after that, updates are silent. First launch may show "unidentified developer" — right-click the app → Open.
